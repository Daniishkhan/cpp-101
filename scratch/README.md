# scratch/: throwaway experiments

This folder is for the small programs you type while reading the book: one idea, one file, run it,
move on. Everything in here except this README is **git-ignored**, so experiment freely and never
worry about tidying up.

```sh
tools/run.sh scratch/hello.cpp            # compile with the Week 1 flags and run
tools/run.sh scratch/args.cpp one two     # pass arguments to the program
```

If something in here turns out to be worth keeping, move it into a challenge or into `docs/`.
